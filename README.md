# Hi, I'm Pavan Dev Singh Charak 👋

AI governance practitioner building practical systems for **policy enforcement, auditability and verifiable AI**.

I'm the founder of [Parmana Systems](https://parmanasystems.com), where we build Parmana: policy-gated execution for AI agents. Every action needs a policy decision and a person's signed approval before it runs, and leaves a signed record anyone can verify offline.

## What I work on

- **Parmana**: policy-gated execution and signed Execution Trust Records for AI agents
- **Governance and compliance**: mapping agent controls to the EU AI Act, NIST AI RMF, ISO/IEC 42001 and RBI guidance
